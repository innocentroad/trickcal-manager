# 編成内使徒タイムライン推定 設計

## 1. 目的

単体DPS計算では選択中使徒だけを正確な行動主体として扱う。編成内の別使徒が持つ時限バフ・デバフについて、本人の発動タイミングを推定し、選択中使徒のDPSへ反映できる試験モードを追加する。

標準設定は`off`とする。未調査データを自動近似して通常結果へ混ぜない。

完全な支援時計を有効化する前段として、編成から軽量なイベント候補を抽出し、利用者が選んだ候補だけを外部イベントへ追加できるようにする。候補は編成・育成・効果設定からDPS入力を作る時に一度だけ生成し、seed試行内では再計算しない。

## 2. モード

| モード | 表示名 | 処理 |
|---|---|---|
| `off` | 編成行動を推定しない | 常時・戦闘開始時・ウェーブ開始時・共通周期だけ反映。本人行動が必要な効果は外部待ち |
| `supportEstimate` | 支援効果のみ推定 | 別使徒の行動時計を生成し、バフ・デバフ・SP・CT・状態付与の発生だけ共有時計へ投入 |
| `fullFormation` | 編成全体DPS | 将来用。別使徒の攻撃ダメージも集計する |

初期実装では`off`と`supportEstimate`だけを対象とする。

## 3. 推定する状態

編成使徒ごとに独立して次を保持する。

- 普通攻撃間隔、基本・強化攻撃の通算回数
- SP、毎秒SP回復、低学年発動待ち
- 高学年CTと発動モード
- 現在行動、終了予定、行動内effectId発生時刻
- 本人の攻撃速度・加速・固有リソース
- 生成物のうち支援効果発生に必要なイベント

選択中使徒と敵状態は共有戦闘状態に置き、別使徒が発生させたバフ・デバフ・状態異常だけを共有イベントキューへ送る。

## 4. 高学年の扱い

編成推定をONにしても、別使徒の高学年は標準で`disabled`とする。高学年はプレイヤー操作やコンテンツ条件の影響が大きいため、次から明示選択する。

- 発動なし
- オート発動
- 初回のみ発動
- 指定秒で発動（将来）

選択中使徒の高学年設定とは分離する。DPS画面の既存「高学年」設定を編成全員へ流用しない。

## 5. データ不足時の方針

| 不足データ | 推定 |
|---|---|
| 普通攻撃間隔なし | その使徒の行動推定を停止 |
| モーションのみ、発生Fなし | モーション終了時発生として明示的に近似 |
| 発動元effectIdの発生Fなし | 固有状態・生成物等は発動させない |
| SP回復量なし | 低学年を発動させない |
| 高学年CTなし | 高学年を発動させない |
| 移動・射程なし | 初動だけ共通設定を利用し、移動差は警告 |

推定不能な効果を選択中使徒の同種行動へ接続しない。

## 6. 効果分類

### 推定モードなしでも反映

- 常時編成効果
- 戦闘開始時
- ウェーブ開始時
- 共通戦闘時計の`n秒ごと`

### 支援タイムラインが必要

- 普通攻撃・強化攻撃・低学年・高学年の使用、終了、命中
- 生成物生成、攻撃、命中、帰還、消滅
- 固有状態・リソースの獲得、消費、終了

### 外部イベントが必要

- 被ダメージ、HP閾値
- 味方戦闘不能、敵撃破
- シールド破壊
- 攻撃対象や配置に依存する条件

支援推定をONにしても、外部イベント条件は自動成立させない。

## 7. UI

DPS計算設定へ「編成行動推定」を追加する。

- 初期値: OFF
- ON時: `推定`バッジと警告を常時表示
- 別項目として「編成高学年」を表示し、初期値は発動なし
- 行動別適用効果では`外部待ち`、`推定待ち`、`推定ON`を区別
- タイムラインには発動者名を表示
- 比較基準には推定モードと編成高学年設定を保存

### 7.1 イベント候補（実装済みの前段機能）

- 「外部イベント（手動）」内の「編成から追加」に候補を表示する
- 同じ編成使徒・同じ行動条件に属する複数効果は1候補へまとめる
- 追加前はDPSへ反映しない。追加後は通常の外部イベントと同様に開始秒・間隔・回数を編集できる
- 高学年はCT、低学年は必要SPと毎秒SP、普通攻撃は調査済み間隔から簡易推定する
- 低学年の行動待ち・モーション、強化攻撃周期など未計上要素は推定根拠へ明記する
- 候補イベントから攻撃速度、時限ダメージ補正、SP回復を発火できる
- 候補配列と手動イベント配列をキャッシュキーへ含め、候補抽出自体はseedごとに走らせない

## 8. 計算結果の区別

推定モードの結果には次を付与する。

```js
{
  formationTimelineMode: 'supportEstimate',
  estimatedActorIds: [],
  skippedActorIds: [],
  estimatedEventCount: 0,
  estimationWarnings: []
}
```

通常の単体DPS結果と推定結果はキャッシュキーを分ける。基準比較でもモードが異なる場合は警告し、自動比較しない。

## 9. 実装順

1. 編成から外部イベント候補を軽量抽出し、選択追加できるようにする（完了）
2. 設定値とキャッシュ・比較キーを追加（標準OFF）
3. 編成使徒ごとの支援時計をWorker内で生成
4. 普通攻撃・低学年起点のバフから対応
5. 高学年オートを別設定で追加
6. 生成物・固有状態・リソースへ拡張
7. 実測と比較し、使徒ごとに推定可否を表示
