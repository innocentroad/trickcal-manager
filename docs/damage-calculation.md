# ダメージ計算と計算式について

この文書は、Trickcal Managerのダメージ計算画面で使用している計算方法をまとめたものです。

ゲーム内で公開された正式な計算仕様ではなく、検証結果とツール上の実装に基づく非公式の計算式です。ゲーム側の仕様変更、新しい効果、データ不足などにより、実際のダメージと差が出る場合があります。

## ダメージ計算画面でできること

ダメージ計算画面では、主に次の情報を組み合わせてダメージを計算します。

- 自キャラまたはPvP敵使徒のステータス
- 使用する基本攻撃、強化攻撃、低学年、高学年スキル
- 編成中の使徒とシナジー
- 本人・編成使徒のスキル、パッシブ、アサイド、愛用カード効果
- 遺物カードとスペルカード
- クレヨンボードなどのステータス補正
- 攻撃力、防御力、会心、会心DMG、各種抵抗
- 属性相性、弱点、与ダメージ、被ダメージ、その他倍率
- 毒、ノイズなどのデバフ

画面中央の攻守切替を使うと、自キャラから敵への攻撃と、敵から自キャラへの攻撃を切り替えられます。

## 計算結果の種類

画面下部には次の結果を表示します。

| 表示 | 内容 |
| --- | --- |
| 通常ダメージ | 会心が発生しなかった場合のダメージ |
| 会心ダメージ | 会心が発生した場合のダメージ |
| 期待値 | 会心率を加味した1回あたりの平均ダメージ |
| 会心率 | 現在の会心と防御側の会心抵抗から計算した確率 |
| 残HP | 表示中のダメージを1回受けた後の防御側HP割合 |

表示ダメージは小数点以下を切り捨てます。内部では切り捨て前の値を使って会心ダメージと期待値を計算します。

## 使用するステータス

ダメージ種別が物理なら物理攻撃力と物理防御力、魔法なら魔法攻撃力と魔法防御力を使います。

「自動」を選んだ場合は、基本的に使徒の攻撃タイプを使用します。攻撃タイプを判定できない場合は、物理攻撃力と魔法攻撃力のうち有効な方を参照します。

以下では、補正前の値を次の記号で表します。

| 記号 | 内容 |
| --- | --- |
| `ATK₀` | 攻撃側の物理攻撃力または魔法攻撃力 |
| `DEF₀` | 防御側の対応する防御力 |
| `CRIT₀` | 攻撃側の会心 |
| `CDMG₀` | 攻撃側の会心DMG |
| `CRES₀` | 防御側の会心抵抗 |
| `CDRES₀` | 防御側の会心DMG抵抗 |

### 補正後ステータス

攻撃力と防御力は、同じ種類の割合補正を先に合計してから基礎値へ掛けます。

```text
ATK = ATK₀ × (1 + 攻撃力補正% / 100)

DEF = max(1, DEF₀ × (1 + (防御力補正% - 防御力低下%) / 100))

CRIT = CRIT₀ × (1 + 会心補正% / 100)

CDMG = CDMG₀ × (1 + 会心DMGステータス補正% / 100)

CRES = max(1, CRES₀ × (1 + (会心抵抗補正% - 会心抵抗低下%) / 100))

CDRES = max(1, CDRES₀ × (1 + (会心DMG抵抗補正% - 会心DMG抵抗低下%) / 100))
```

物理攻撃力増加は物理攻撃時、魔法攻撃力増加は魔法攻撃時だけ攻撃力補正へ加えます。単に「攻撃力増加」となっている効果は、現在選択しているダメージ種別へ適用します。

## 防御係数

補正後の攻撃力と防御力の比率から、防御係数を計算します。

```text
x = ATK / DEF
```

`x ≥ 0.5` の場合：

```text
防御係数 = 1.2 × (1 - 0.5 / (1 + (10 / 3) × (x - 0.5)))
```

`x < 0.5` の場合：

```text
防御係数 = 0.6 × (1 - ((13 / 3) × (0.5 - x)) / (1 + (10 / 3) × (0.5 - x)))
```

最後に防御係数を `0.1125～1.2` の範囲へ制限します。

したがって、防御係数だけで見ると最低11.25%、最大120%です。

## 通常ダメージの計算式

会心が発生しなかった場合のダメージは、次の式で計算します。

```text
通常ダメージ
= ATK
 × 防御係数
 × スキル倍率
 × 与ダメージ係数
 × 属性相性係数
 × 特殊係数
 × その他係数
```

画面で百分率表示される倍率は、計算時に100で割って使用します。例えば250%は `2.5`、75%は `0.75` です。

### スキル倍率

選択した行動の倍率です。基本攻撃、強化攻撃、低学年、高学年スキルのほか、火傷などの独立した状態異常ダメージも行動として選択できます。

現在設定している状態異常倍率は次のとおりです。

| 状態異常 | スキル倍率 |
| --- | ---: |
| 火傷 | 30% |
| 毒 | 6% |
| 苦痛 | 12% |
| 凍傷 | 9% |

### 与ダメージ係数

与ダメージ増加と防御側の被ダメージ増減は同じグループで加減算します。

```text
与ダメージ係数
= max(0.2, 1 + (攻撃側の与ダメージ補正% - 防御側の被ダメージ補正%) / 100)
```

最低値は20%です。

攻撃側の与ダメージ補正には、条件が一致している場合に次の効果も加わります。

- 全行動に適用される与ダメージ増減
- 普通攻撃全体への補正
- 基本攻撃だけへの補正
- 強化攻撃だけへの補正
- 低学年・高学年などのスキル攻撃への補正
- 敵プリセットの弱点補正

毒とノイズによる攻撃側の減少値も、このグループへ加えます。

```text
毒 = 1スタックにつき -11%（最大9スタック）
ノイズ = -50%
```

### 属性相性係数

画面の「属性相性」で選択した値です。現在は50%、75%、100%、150%、200%から選択できます。

PvP補正を想定する場合は、不利75%、有利150%を選択します。敵プリセットの「物理弱点」「魔法弱点」は属性相性ではなく、前述の与ダメージ補正へ加算されます。選択中のダメージ種別と弱点種別が一致しない場合、弱点補正は適用しません。

### 特殊係数とその他係数

特殊係数とその他係数は、与ダメージ係数や属性相性係数とは別に乗算します。

アサイドなどで「その他倍率」と明記されている効果は、与ダメージ補正へ混ぜず、その他係数へ加算します。同じ「その他」グループ内の効果は加算し、完成した係数をダメージ式へ乗算します。

## 会心率

補正後の会心と会心抵抗の比率を使います。

```text
y = CRIT / CRES
```

`y ≥ 1` の場合：

```text
基礎会心率 = 0.30 + 0.50 × (y - 1) / (y + 2)
```

`y < 1` の場合：

```text
基礎会心率 = 0.05 + 0.25 × y / (2 - y)
```

会心率加算と防御側の会心率抵抗加算を反映します。

```text
最終会心率
= clamp(
    基礎会心率
    + 会心率加算% / 100
    - 会心率抵抗加算% / 100,
    0.05,
    0.80
  )
```

会心率の下限は5%、上限は80%です。

## 会心倍率

補正後の会心DMGと会心DMG抵抗の比率を使います。

```text
z = CDMG / CDRES
```

`z ≥ 1` の場合：

```text
基礎会心倍率 = 1.75 + 0.85 × (z - 1) / (z + 2)
```

`z < 1` の場合：

```text
基礎会心倍率 = 1.75 - 1.10 × (1 - z) / (2 - z)
```

会心DMG倍率加算と防御側の会心DMG抵抗加算を反映します。

```text
最終会心倍率
= clamp(
    基礎会心倍率
    + 会心DMG倍率加算% / 100
    - 会心DMG抵抗加算% / 100,
    1.2,
    2.5
  )
```

会心倍率の下限は1.2倍、上限は2.5倍です。

```text
会心ダメージ = 通常ダメージ × 最終会心倍率
```

## 期待値

通常ダメージ、会心ダメージ、最終会心率から計算します。

```text
期待値
= 通常ダメージ × (1 - 最終会心率)
 + 会心ダメージ × 最終会心率
```

これは1回の攻撃に対する平均値です。攻撃速度、クールタイム、行動時間を含む秒間ダメージではありません。

## 残HP

```text
残HP割合
= clamp((防御側HP - ダメージ) / 防御側HP × 100, 0, 100)
```

HP表示を有効にしている場合、通常ダメージ・期待値・会心ダメージごとに残HPを表示します。

## 計算例

次の条件を例にします。

```text
補正後攻撃力: 1,000
補正後防御力: 1,000
スキル倍率: 250%
与ダメージ補正: +20%（係数120%）
属性相性: 150%
特殊: 100%
その他: 100%
補正後会心: 1,000
補正後会心抵抗: 1,000
補正後会心DMG: 1,000
補正後会心DMG抵抗: 1,000
```

攻撃力と防御力の比率は1なので、防御係数は97.5%です。

```text
通常ダメージ
= 1,000 × 0.975 × 2.5 × 1.2 × 1.5 × 1 × 1
= 4,387.5

画面表示: 4,387
```

会心と会心抵抗の比率が1の場合、会心率は30%です。会心DMGと会心DMG抵抗の比率が1の場合、会心倍率は1.75倍です。

```text
会心ダメージ = 4,387.5 × 1.75 = 7,678.125
画面表示: 7,678

期待値
= 4,387.5 × 0.7 + 7,678.125 × 0.3
= 5,374.6875

画面表示: 5,374
```

## 効果の適用とオン・オフ

スキル、アサイド、愛用カード、遺物、スペルなどの効果は、データに設定された条件と現在選択している行動・使徒・編成を照合して適用します。

- 常時効果や編成時効果は、条件を満たす場合に自動でオンになります。
- 「低学年スキル使用時」などの行動条件は、該当する行動を選んだ場合だけオンになります。
- 戦闘開始時、ウェーブ開始時などの再現可能な効果は、自動または初期オンとして扱う場合があります。
- 確率、攻撃回数、被撃回数など、画面だけでは現在状態を判断できない効果は手動トグルで調整します。
- スタック可能な効果は、表示されたスタック数を変更して計算します。
- 同効果非スタック、同一使徒非スタックなどの設定がある場合は、その重複ルールを優先します。
- オフにした効果は計算へ加えません。

「詳細」および各効果のインフォでは、最終ステータス、補正値、発動条件、対象、効果時間などを確認できます。

## 現在の計算に含まれないもの

この画面は、選択した1回の行動に対するダメージを求める計算機です。現在は主に次の要素を直接シミュレーションしません。

- 攻撃モーションと硬直を含む秒間ダメージ
- 高学年スキルのクールタイムを使った長時間DPS
- 複数ウェーブを通した効果時間と再発動
- 普通攻撃によるSP回復
- 確率発動の長時間平均
- 攻撃回数・被撃回数・撃破数の自動進行
- 敵の行動順、移動、範囲、対象数
- 多段攻撃ごとの個別判定や途中で変化するバフ・デバフ

高学年スキルのクールタイムや、低学年スキルのSP回復間隔は参考情報として表示しますが、現在のダメージ値そのものを時間平均へ変換するものではありません。

## 数値が合わない場合の確認項目

実際のダメージと差がある場合は、次の項目を確認してください。

1. 物理・魔法のダメージ種別が正しいか
2. 攻撃側と防御側のステータスが最新か
3. 学年、装備、スキルLv、アサイドLvが正しいか
4. 使用する行動とスキル倍率が正しいか
5. 属性相性と弱点種別が一致しているか
6. スキル・カード・スペル効果のトグルが正しいか
7. スタック数と同効果非スタック設定が正しいか
8. 効果時間内、戦闘開始時、ウェーブ開始時などの条件を満たしているか
9. 敵プリセットの防御力、抵抗、特殊補正が正しいか
10. ゲーム内で乱数や個別の丸め処理が行われていないか

計算画面の「詳細」を開くと、補正前後のステータス、最終補正値、会心率・会心倍率の上限または下限到達を確認できます。
