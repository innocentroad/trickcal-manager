# Codex表示検証環境

生成済みの使徒・カード・ボードデータから、公開状態に合わせた「全育成最大」状態を作成して表示検証に使う。

## fixtureの生成・検証

```powershell
node tools/create-max-growth-state.js
node tools/test-max-growth-state.js
```

`tools/fixtures/max-growth-verification-state.json` は既存の `trickcal-stat-state` version 2 のスロットファイルとして、ステータス管理画面のインポートからも読み込める。

## ブラウザで適用

ローカルHTTPサーバーでリポジトリを配信し、次のページを開く。

```text
tools/max-growth-verification.html
```

「最大育成状態を適用」を押すと、次の状態を行う。

- スロット6だけを最大育成 fixtureへ置き換える
- 現在のスロットストア、共有状態、編集中ドラフトを退避する
- ステータス管理・ダメージ計算の次回読み込みへ最大状態を反映する

スロット1〜5は変更しない。適用前の状態は同じページの「適用前の状態を復元」から戻せる。

## 含まれる最大状態

- 全使徒: Rank9、★5、Lv145、等級6
- 好感度: レア1以外Lv30
- アサイド: 公開有効かつデータがある使徒のみA3/Lv50、スキル最大Lv15
- 装備: データ上存在するRank9装備を有効化、+5
- ボード: スタートマス以外の全ノードを開放
- 研究: 段階10、45回目
- 全アーティファクト／スペル: 所持、★5、はんだ+2

フォロー、編成、スペル、マスターパワー、敵、DPS条件は育成状態ではなく検証条件のため、fixtureでは初期状態にしている。ギデオンのアサイドは公開無効化設定に従い含めない。
