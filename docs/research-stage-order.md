# 研究段階と取得順

`tools/trickcal_datasheet.xlsx` の新「研究効果」シートが公開データの正本。1行が1研究で、`研究ID`は行固有、`段階`と`取得順`で表示・適用順を決める。Excel行番号や旧効果IDは使わない。「研究効果_旧」は移行照合専用で、公開データには出さない。

- 段階内の取得順は1から欠番・重複なく並べる。`種族`と`ステータス`が両方記入された行の`増加値`だけをステータス計算へ加える。非ステータス効果は原値を表示し、無理に数値計算へ混ぜない。
- 「研究素材」は研究ID・段階の完全一致で研究と結び、素材名は素材マスターと完全一致させる。レシピ・施設の材料1/2と必要数1/2は組で扱う。欠損と明示0を区別し、重複・欠番・参照切れ・不正数量は生成時にシート・行・列を示して停止する。
- 研究時間・製作時間の入力単位はユーザー確認済みの秒。レシピ完成数はxlsx入力値であり、実機確認済みとは記録しない。施設強化費用は参照検証するが、研究段階の費用へ加算しない。

保存形式は従来の `{level, progress}`。段階 `level` より前は各段階に存在する取得をすべて反映し、現在段階は取得順が `progress` 以下のものだけ反映する。どちらかが0なら研究OFF。段階・回数の上限は検証済みの生成データから求める。

素材マスターシートが未追加の間は`tools/research-material-master.tsv`（素材名・画像キーの2列）を単一の代替入力にする。将来xlsxに「素材マスター」シートを追加したら、生成器はそのシートを優先しTSVを参照しない。両方を手管理しない。`画像キー`と生成後の`imageKey`は、`.png`または`.webp`の**拡張子付きファイル名**を意味する。日本語名も許可するが、パス・URL・存在しないファイルは生成時に拒否し、空欄だけは画像なしとして扱う。画像は`img/Materials/`に27 PNG＋ゴールドWebPの計28枚。公開側では既存のprofile-awareな資材URLを使う。抽出runの内部パスは公開データへ含めない。

閲覧段階と終了段階は画面内だけの状態で、保存中の研究進行度や計算値を変えない。研究素材計画は保存進行度から終了段階の最後までを対象にし、段階別直接数は所持控除前の総需要を表示する。製作ツリーは生成済みレシピの完成数と材料を原材料まで辿り、共有材料の需要を合算してから所持数を一度だけ差し引く。レシピの循環・参照切れ・不正数は結果を表示せず停止する。所持数は独立した`trickcal_research_inventory_v1`にのみ保存し、計画操作で自動消費しない。製作時間短縮、実所要時間、施設費用・施設Lvや開放条件の判定は行わない。データ行の存在を現行ゲームでの開放と解釈しない。

研究画面は進行度→取得順一覧→選択使徒の効果→種族別合計→素材計画の順。後二つの効果欄は初期折畳み。素材計画は残り研究／所持素材の2タブ。研究の取得状態は操作不能なチェック表示とし、進行度の変更は上部設定だけで行う。集計欄は直接必要な素材と製作に必要な原材料を示し、素材アイコン右下に数量を重ねる。中間・完成素材の製作必要数は集計から省き、製作ツリー内で確認する。研究一覧・費用の素材内訳・残り研究の集計欄から素材を選ぶと、その場で製作ツリーのモーダルを開き、ページは自動スクロールしない。素材名と段階別直接使用数はモーダルに表示する。ツリー上は画像と数量を主表示にし、素材名と製作詳細はノードの選択・フォーカス時に表示する。閲覧段階・計画モード・ツリー選択は保存進行度へ影響しない。

ゴールドは研究費用欄で扱い、所持素材タブの一覧には出さない。カタログの画像定義は維持し、旧所持数キーにゴールドが残っていても読込・再保存時に破棄しない。

所持数キーの旧形式は素材名→整数のJSON object。新規保存は`{version:2, items:{素材名:整数}, updatedAt:ISO日時}`とする。`items`にない素材は未入力（一覧では—）、明示的な0は確認済み0で、計算上は両方0。未保存なら更新日時を表示せず、旧形式に日時がなければ「更新日時不明」と表示し、読み込むだけでは書き換えない。所持素材タブの素材アイコンから個別入力モーダルを開き、選択素材だけを下書きする。保存時は研究所持数専用Web Lockの排他区間で最新値を読み直し、選択素材が編集中に変更されていれば競合を拒否し、他素材の新しい値は維持する。排他機能が利用できない環境では保存しない。待機中の二重入力を抑止し、書込成功後だけ計画と日時を更新する。失敗時は下書きと既存保存を残す。変更済み入力を閉じる際は確認する。所持数はゲームと自動同期しない。
