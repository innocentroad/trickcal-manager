# 研究段階と取得順

`tools/trickcal_datasheet.xlsx` の「研究効果」シートは、`id` を効果行の識別子として使う。取得順を変えても ID は変えない。

- 各段階の値は `段階N` 列に記入する。11段階以降は同じ番号の `取得順N` 列が必須。
- 1〜10段階には取得順列がないため、値がある行の ID が取得順になる。値が空欄の行はその段階に存在しない。0 は空欄と異なり、取得枠を占める値として扱う。
- 11段階以降は値と取得順を両方記入するか、両方空欄にする。段階内の取得順は1から欠番・重複なく並べる。将来の段階を増やす場合も `段階N` と `取得順N` の組を追加する。
- `種族` と `ステータス` が両方記入された行の段階値は数値とする。両方空欄の説明行には文字列を記入できるが、ステータス計算には加えない。

保存形式は従来の `{level, progress}`。段階 `level` より前は各段階に存在する取得をすべて反映し、現在段階は取得順が `progress` 以下のものだけ反映する。どちらかが0なら研究OFF。段階・回数の上限は検証済みの生成データから求める。
