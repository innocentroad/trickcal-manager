# リニュア高学年スキル：加速の仮設計

更新日: 2026-09-07。ユーザー指定に基づく暫定仕様。10秒持続と加速曲線を実装済み。

## 加速曲線

加速開始を `t = 0` とし、`t` は加速自身によって短縮しない経過秒数とする。
スキル設定の加速値を百分率の数値 `p` とする（Lv15なら `p = 76`）。

- 0～8.5秒: 加速量0%から `3p%` まで線形に増加する。
- 8.5～10秒: 最大加速量 `3p%` を1.5秒間維持する。
- 10秒で本効果を終了する。終了後に減速区間は設けず、本効果の寄与を0に戻すことを暫定案とする。
- 対象は既存スキルデータどおりフィールド上の味方全体。

```text
accelerationP(t) =
  0                 (t < 0)
  3 * p * t / 8.5   (0 <= t < 8.5)
  3 * p             (8.5 <= t < 10)
  0                 (10 <= t、終了後の暫定案)

speedMultiplier(t) = 1 + accelerationP(t) / 100
```

3倍にする対象はスキルの加速値。基準速度100%には3倍を掛けない。
上式の速度倍率は他の速度効果がない場合を表す。

## Lv15の確認値

`p = 76` より最大加速量は228%、最大速度は328%（3.28倍）。

| 加速開始からの時間 | 加速量 | 基準速度に対する速度 |
|---|---:|---:|
| 0秒 | 0% | 100% |
| 4.25秒 | 114% | 214% |
| 8.5秒 | 228% | 328% |
| 9秒 | 228% | 328% |
| 10秒直前 | 228% | 328% |
| 10秒・終了後（暫定） | 0% | 100% |

曲線の確認用に、10秒間の速度倍率の積分は
`8.5 * (1 + 3.28) / 2 + 1.5 * 3.28 = 23.11` 秒相当。
平均速度は231.1%となる。これは連続的な行動進行量の確認値であり、DPS倍率や攻撃回数を直接表すものではない。

## 既存データ・実装との関係

- `apostles.js` の `Renewa_high_e01` がスキルレベル別の加速値を保持している。Lv1は20%、Lv15は76%。この元の値を228%へ書き換えず、仮設計側で3倍する。
- `Renewa_high_e02` の持続時間は実測仮定に合わせ、正本Excelと生成済み`apostles.js`を10秒へ更新した。敵側の`Renewa_high_e06`（減速持続時間7秒）は変更していない。
- `docs/dps-simulation-design.md` 第9節では、普通攻撃の攻撃速度補正と全行動の加速を区別している。本効果を通常の `hasteP` に置き換えない。
- `dps-simulator.js` は`accelerationEffects`として扱い、行動進行量を速度の時間積分で計算する。`dps-timing-data.js`の`Renewa_high_e01`発生フレームを加速開始点に使う。

## 暫定実装の残課題

今回確定するのは加速開始後の曲線。次の点はこの曲線から自動的には決まらない。

- 高学年使用開始から加速開始までの遅延。
- 「全行動速度」がCT、SP自然回復、生成物の周期にも作用するか。現実装は行動モーションと普通攻撃間隔を対象にする。
- 進行中の行動を連続的に伸縮するか、行動開始時の倍率を保持するか。現実装は前者で、速度の時間積分で行動進行を計算する。
- 他の加速・攻撃速度との合成順序と、効果中の再使用時の更新規則。
- 10秒後の終了挙動。現実装は即時解除で、敵側の減速など別効果の仕様を変更しない。

これらを決める際は共通の時間モデルへの影響を確認し、既存の攻撃速度処理を暗黙に変更しない。
