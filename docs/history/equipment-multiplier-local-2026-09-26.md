# 装備効果の基礎値・強化倍率対応（2026-09-26、ローカル）

## 入力と今回の範囲

利用者が旧シートを「装備効果_旧」、新シートを「装備効果」に変更した。
新シートの列は `rank / ステータス / tier / 装備名 / 強化なし / 強化倍率+1 … 強化倍率+5`。
`強化なし` は基礎値。各倍率は基礎値に対する倍率であり、直前の強化値へ掛けるものではない。
旧シートは照合用として維持し、生成入力に使わない。

- `tools/equipment_data.py` を生成器と生成前検証で共用し、各 `enhanceN` に基礎値×倍率を出力。
- 赤いエプロンの+1は1707×1.07=1826.49、+2は1707×1.14≒1945.98。途中切捨て・小数桁丸め・epsilon補正をしない。
- JS生成上の `1945.9799999999998` 等はbinary64の値を保持したもの。表示側だけ既存の数値書式を使用する。
- 空欄・不正数・非有限値・1未満の倍率・重複キーを生成前に拒否。旧 `強化+N` への暗黙fallbackはしない。
- 管理画面・共通計算・使徒データ画面は既存の `enhanceN` 消費経路を維持。装備集計・内訳・比較保存は小数を保持しており、修正不要だった。
- 計算版を2→3（共通エンジン版7→8）に更新。比較圧縮形式のschema v2は変更していない。

v33全体の実装ではない。基礎ステータスの早期floor、全体％補正の増分floor、好感度のfloat32演算、全加算の順序などは今回変更していない。v29戦闘力式自体も変更していない。装備の小数を戦闘力入力まで保持する変更である。

## 保存互換性

旧計算版の結果を新計算版として再使用しない。元の育成設定と内訳が照合できるものだけ既存の読み取り専用再計算を行う。旧装備整数と新装備小数の不一致を丸め一致などで許容しない。
