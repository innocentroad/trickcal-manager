# Trickcal Manager

## Entry

- `index.html`: ステータス管理
- `formation-damage-calc.html`: 編成ダメージ計算

## Notes

- `stat-prototype.css` と `stat-prototype.js` はステータス管理画面の既存実装を利用するため残しています。
- 旧計算機の `calculator/index.html` はこのディレクトリでは扱いません。
